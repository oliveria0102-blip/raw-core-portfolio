# RAW Core · 跨智能体协作基础组件作品集

RAW（Research Agent Workspace）面向异构智能体协作中的消息、投递、执行证据与人工决策管理。作者主导需求、架构裁定、集成和验收，并使用 AI 辅助设计与开发。

本仓库公开精选核心代码及可复现的离线合成演示。完整部署、浏览器适配、真实通信与研究项目保持私有。

## 解决什么问题

消息进入收件箱、目标客户端看到消息、目标执行任务、人工接受结果，是不同事件。RAW 将它们分别记录，避免把“已发送”直接当作“已完成”。

| 对象 | 作用 |
| --- | --- |
| Message | 固定任务内容和幂等标识 |
| DeliveryAttempt | 记录每次投递尝试和可见性证据 |
| Execution | 分开表达回执、执行及证据状态 |
| HumanDecision | 将接受或拒绝决定绑定到身份和证据摘要 |

核心实现包括 SQLite 事务与迁移、内容不可变约束、追加事件、幂等冲突处理，以及经验证身份的授权接口。源码入口是 `src/core.js`；存储和身份实现分别在 `src/db-versioned.js` 与 `src/discussion-identity.js`。

## 运行演示

使用 Node.js 22.5+（本次验证环境为 Node.js 24），不需要安装第三方 npm 包：

```bash
npm test
```

演示会建立新的 `work/demo-<随机标识>/`，保留合成数据库和检查结果。不会调用外部模型、访问网页会话或读取生产数据库。每次运行使用新目录，不清理既有数据。

检查覆盖：消息写入、重复复用、冲突拒绝、内容不可变、投递记录、无摘要可见性拒绝、回执与执行分离、无证据执行拒绝、伪造身份拒绝、合成人工身份决策、重开持久化、数据库完整性。

## 证据与成熟度边界

此公开版是组件作品集，不是完整的自动化平台发行版。合成测试不证明真实模型执行、实际浏览器投递或生产恢复已经验收。

执行记录接口会根据调用方提交的证据等级映射状态；本身不独立证明远端行为真实发生。可信的证据收集和验证仍属于集成方责任。测试中的人工身份由脚本为合成场景临时 provision，不代表真实用户授权流程。

现有内部 G1 测试报告包含测试范围与总体验收的明确区分，本仓库不把历史测试报告作为当前整体系统验收结论。实验性原型与生产配置没有随包公开。
